# Fernanda & Sávio — 21.08.2027

Site do casamento (estático: HTML + CSS + JS, sem build), publicado via GitHub Pages em https://fernandaesavio.com.br

- `index.html` — página
- `styles.css` — estilos (desktop + mobile)
- `app.js` — contagem regressiva, indicações, lista de presentes e Pix
- `qr.js` — gerador de QR Code (sem dependências)
- `CNAME` — domínio personalizado do GitHub Pages

Pix: editar `PIX_KEY`, `PIX_NAME` e `PIX_CITY` no topo de `app.js`.
